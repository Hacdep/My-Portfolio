# Behruz Baxtiyorov — Portfolio

React + Vite. Tillar: UZ / EN / RU.

## Ishga tushirish
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tayyor sayt dist/ papkasiga chiqadi
```

## Nimani o'zgartirish kerak
`src/App.jsx` ning tepasida:
- `ME` — email, telefon, GitHub, Telegram, resume (Google Docs ID)
- `T` — barcha matnlar (uz / en / ru), loyihalar `P` ichida
- `EXTRA` — ko'nikmalar, ta'lim, tillar
- Rasm: `src/assets/photo.jpg`

## Joylash
- **GitHub Pages**: `npm run build`, so'ng `dist/` papkasini joylang
- **Vercel / Netlify**: GitHub repo'ni ulang (Build: `npm run build`, Output: `dist`)
